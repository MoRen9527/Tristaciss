# Tristaciss Registry Layer

## 作用

本目录承接 `TristacissBusinessStrategyRegistry`、`TristacissProductRegistry` 和 `TristacissCodeRegistry` 的工作型资料。

## 真源优先级

1. `../../AGENTS.md`
2. `../../CLAUDE.md`
3. 相关部署文档、PRD 和架构文档
4. 本目录中的登记文档

## 当前文件

- `business-state.md`：Tristaciss 的商业模式、默认职责与边界
- `product-state.md`：Tristaciss 的产品状态、模块职责与依赖
- `code-state.md`：Tristaciss 的代码结构、健康状态与风险

## 更新规则

- 只有在用户明确要求“记录”或“更新”时才修改本目录。
- 在 `TristacissProductRegistry` 建立 README 基线前，不把根目录 `README.md` 当唯一产品真源。
